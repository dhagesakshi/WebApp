# Learning Dashboard — Web Version

A responsive browser-based version of the Learning Dashboard design, built with HTML, CSS, and vanilla JavaScript. No build tools or package installation are required.

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for GitHub Pages to publish the site. The public link will appear in the Pages settings.

## Notes
- This is a front-end demonstration with sample dashboard statistics and course cards.
- Course buttons, search, chart range selection, and navigation have simple demo interactions.
- It does not contain a backend, user login, or real course data.
